  - Add new features
  - Change the architecture
  - Modify the workflow
  - Find missing information

### Key Files to Update

| Change | Update |
|--------|------------|
| New feature | `changelog.md`, relevant code |

| New technology | `TECH_STACK.md`, `package.json` |
