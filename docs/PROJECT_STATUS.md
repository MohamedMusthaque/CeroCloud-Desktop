**Goal:** A complete inventory and sales management system with enterprise-grade security.

### ✅ New Features (January 2026)

#### "Premium Glass" Backup System
- **Immersive Interface:** Modals with glassmorphism effects, dynamic shadows and refined typography.
- **Controlled Flow:** The user decides when to download; forced automatic downloads were removed.
- **Visual Cloud Integration:** Official cards for Google Drive and Dropbox with their corporate branding.
- **Constant Feedback:** Loading, success and error indicators with smooth animations (Sonner + Framer Motion).

#### Restore Wizard 2.0
- **Smart Drag & Drop:** Reactive upload zone with immediate visual validation.
- **Security first:** Automatic detection of encrypted backups and an elegant password prompt.
- **Data Preview:** A statistics grid (Products, Sales, Date) visible BEFORE confirming the restore.
- **Integrity Protection:** Strict validation of the .cerobak structure and checksums (implicit in the ZIP format).

#### Reinforced Security
- **AES-256 Encryption:** Optional protection for backup files using industry standards.
- **Service Architecture:** Decoupled, testable `zipBackupService` and `secureEncryptionService`.
